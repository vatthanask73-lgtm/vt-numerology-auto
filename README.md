# vt-numerology-auto

A lightweight numerology helper library for calculating life-path, expression, soul, and personality numbers. The project exposes a Python package (`numerology_ast`) and a Node entry point (`src/index.js`).

Examples:

- `calculate_life_path("1990-08-15")` -> `6`
- `calculate_expression_number("Alice")` -> `3`
- `calculate_report("Alice", "1990-08-15")`
